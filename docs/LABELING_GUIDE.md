# 중고 매물 정규화 라벨링 가이드 (v1.2: 아이폰 / 갤럭시)

입력: 매물 `title`(제목) + `body`(본문 또는 검색 스니펫). 출력: 아래 JSON 한 줄.

```json
{"post_type": "sell", "category": "phone", "models": ["아이폰 12 미니"], "storage": ["128GB"], "color": ["네이비"], "condition": "used"}
```

v1.1 변경 (2026-10-08): `condition` 필드 추가. 시세를 미개봉 / 중고 / 하자·고장으로 나눠 계산하기 때문이다.
v1.2 변경 (2026-10-08): 평가셋 라벨링에서 애매했던 경우의 기준을 정했다. condition 의 하자 기준, 업체 글, 박스·대여, 모델 코드, 용량 오타 등. 아래 "애매한 경우" 절 참고.

## 필드

### post_type (하나)
- `sell`: 판매글. 개인이든 업체든 **특정 상품**을 파는 글. 무료나눔, 부품용 고장폰 판매도 sell.
- `buy`: 구매·매입 희망글 ("삽니다", "구해요", "매입", "구매합니다").
- `shop_ad`: 업체 홍보·대량판매 광고. 특정 1~2개 상품이 아니라 여러 모델 이름을 나열한 홍보글 (예: "중고폰 파손폰 매입 전문", "대량판매 당일발송 ... 노트9 노트10 z플립3 ...").
  - 업체라도 특정 상품 1개를 파는 글은 `sell` (예: "아이폰16 128기가 화이트 AAA급 - 울산중고폰").
- `other`: 교환 희망만 있는 글, 정보·후기글, 그 밖에 판매·구매가 아닌 글.

### category (하나), 판매·구매 대상의 종류
- `phone`: 스마트폰 본체 (고장폰, 부품용 폰, 공기계 포함)
- `tablet`: 아이패드, 갤럭시 탭
- `watch`: 애플워치, 갤럭시 워치
- `earbuds`: 에어팟, 갤럭시 버즈
- `laptop`: 맥북, 갤럭시 북
- `accessory`: 케이스, 필름, 충전기, 케이블, 거치대, S펜 단품, 스트랩 같은 주변기기
- `parts`: 분리된 부품 단품 (액정, 메인보드, 배터리, 카메라 모듈 등)
- `other`: 위 어디에도 속하지 않음 (예: 판매자 닉네임 때문에 검색된 가방)

`shop_ad`는 주로 다루는 대상을 고른다 (중고폰 매입·판매 광고면 `phone`).

### models (리스트), 대상 기기의 정식 한국어 모델명
- 단일 상품이면 원소 1개. 서로 다른 모델 여러 개를 함께 팔면 모두 넣는다 (예: "아이폰 13, 14 일괄").
- `shop_ad`는 `[]`.
- `accessory`·`parts`는 **호환·대상 기기**를 적는다 (예: 아이폰 16 프로 케이스 → `["아이폰 16 프로"]`).
- 텍스트에서 확정할 수 있는 만큼만 적는다. 세대를 알 수 없으면 `"아이폰"`, `"갤럭시 Z 플립"`처럼 적는다. 추측해서 세대를 채우지 않는다.
- 제목과 본문이 다르면 제목을 우선한다. 단, 제목이 "아이폰 팝니다"처럼 비어 있고 본문에 모델이 있으면 본문을 쓴다.
- 통신 규격(5G/LTE), 자급제·통신사, 국가판(북미판), 램 용량은 모델명에 넣지 않는다.

정식 표기 규칙. 띄어쓰기는 평가에서 무시하지만 아래 형태를 지킨다.
- 아이폰
  - `아이폰 {세대} [미니|플러스|프로|프로 맥스]`. 세대: 4, 4S, 5, 5C, 5S, 6, 6S, 7, 8, X, XS, XR, 11 … 18
  - 특수 모델: `아이폰 XS 맥스`, `아이폰 SE`(1세대 또는 세대 불명), `아이폰 SE 2세대`, `아이폰 SE 3세대`, `아이폰 16e`, `아이폰 17e`, `아이폰 에어`
  - `아이폰 SE 2세대`, `아이폰 SE 3세대`는 텍스트에 세대 단서(2세대, 3세대, 2020, 2022)가 있을 때만 쓴다.
  - 미니·프로·프로 맥스는 실제로 그 세대에 존재할 때만 쓴다 (예: 12, 13에만 미니가 있다).
  - 예: "아이폰12미니" → `아이폰 12 미니`, "14pro" → `아이폰 14 프로`, "프맥", "promax" → `프로 맥스`, "아이폰 텐" → `아이폰 X`
- 갤럭시 S: `갤럭시 S{번호} [플러스|울트라|FE|엣지]`
  - 예: `갤럭시 S24 울트라`, `갤럭시 S25 엣지`, `갤럭시 S7 엣지`, `갤럭시 S23 FE`. "S24+" → `갤럭시 S24 플러스`
- 갤럭시 노트: `갤럭시 노트{번호} [플러스|울트라]`
  - 예: `갤럭시 노트20 울트라`, `갤럭시 노트10 플러스`, `갤럭시 노트 FE`
- 갤럭시 Z
  - 폴드·플립: `갤럭시 Z 폴드{번호}`, `갤럭시 Z 플립{번호}`, `갤럭시 Z 플립{번호} FE`
  - 1세대: `갤럭시 폴드`(2019), `갤럭시 Z 플립`(1세대)
  - 그 밖에: `갤럭시 Z 폴드 스페셜 에디션`, `갤럭시 Z 트라이폴드`
  - 예: "폴드5", "z폴드5", "갤폴5" → `갤럭시 Z 폴드5`
- 기타 갤럭시: `갤럭시 A{번호}`, `갤럭시 퀀텀{번호}`, `갤럭시 와이드{번호}`, `갤럭시 점프{번호}`, `갤럭시 버디{번호}`, `갤럭시 M{번호}`, `갤럭시 J{번호}`
  - 예: `갤럭시 A54`, `갤럭시 퀀텀5`, `갤럭시 J7 2016`은 `갤럭시 J7`
- 폰이 아닌 기기: 자연스러운 정식명 (예: `갤럭시 탭 S9`, `갤럭시 버즈3 프로`, `애플워치 SE`, `아이패드 프로 11`). 이 범주의 모델명은 평가하지 않는다.

### storage (리스트)
- 판매 대상의 저장 용량을 `"64GB"`, `"128GB"`, `"256GB"`, `"512GB"`, `"1TB"` 형태로 적는다.
  - "128기가", "128g", "128G", "128"처럼 맥락상 용량이 명확한 숫자도 포함한다.
- RAM(램 8기가)은 넣지 않는다. 언급이 없으면 `[]`.
- 여러 용량을 판다면 모두 넣는다.

### color (리스트)
- 판매자가 적은 **색상명**을 한국어 표기로 적는다. 제목을 우선하고, 제목에 없으면 본문을 본다.
- 공식 색상명으로 바꾸지 않고 적힌 대로 적되, 영어·약어는 한국어로 풀어 쓴다.
  - "white" → `화이트`, "스그" → `스페이스 그레이`, "블랙티타늄" → `블랙 티타늄`
  - "흰색" → `화이트`, "검정" → `블랙`
  - "네이비" → `네이비`
- 여러 색을 판다면 모두 넣는다. 언급이 없으면 `[]`.

### condition (하나), 판매 대상의 상태
- `new`: 사용하지 않은 새 상품. 미개봉, 단순 개봉(개봉만 하고 쓰지 않음), 새상품, 새제품, 미사용, 가개통·개통만 하고 쓰지 않음.
  - "S급", "새것 같은", "새폰급", "리퍼 받은 폰", "개봉 후 일주일 사용"은 `used`.
- `broken` (서비스 표시: 하자·고장): 기기 자체에 하자나 고장이 있다고 적힌 경우. **판매자가 "사용에 지장 없다"고 적어도 하자가 있으면 broken.**
  - 예: 고장, 파손, 액정·뒷판 깨짐이나 금(실금 포함), 화면 줄·멍·번인·잔상·데드픽셀·반점 있음(작거나 약해도), 터치·페이스ID·카메라·스피커·버튼 불량, 카메라 렌즈·보호유리 깨짐, 침수, 전원 안 켜짐, 부품용, 아이클라우드·활성화 잠금.
  - 하자가 "없다"고 적힌 경우("깨짐 없음", "무잔상")는 하자가 아니다.
  - 강화유리·보호필름만 깨진 경우, 이미 수리를 마친 경우(액정 교체 완료 등)는 `used`.
  - 사설 수리 부품이라 일부 기능이 빠진 경우(사설 액정이라 120Hz 안 됨 등)는 `broken`.
- `used`: 그 밖의 중고. 생활 기스, 찍힘, 배터리 성능 저하만 있는 경우도 `used`.
- 구매글·광고글처럼 판매 대상이 없으면 `used`로 둔다 (평가하지 않음).

## 애매한 경우 (v1.2)
- 업체 글
  - 한 모델을 용량·색상 옵션별로 파는 글은 `sell`.
  - "대량)", "대량판매"처럼 대량으로 파는 글은 모델 수와 관계없이 `shop_ad`. 매입 업체 광고("다수 매입", "최고가 매입")도 `buy`가 아니라 `shop_ad`.
  - 개인이 서로 다른 모델 여러 대를 함께 파는 글은 `sell`이고 모델을 모두 적는다.
- 폰 대여·렌탈 글은 `other`. 업체의 대여 광고는 `shop_ad`.
- 박스·구성품만 파는 글("폰 빼고", "빈 박스")은 `accessory`이고 models는 그 박스의 기기, storage·color는 `[]`.
  - "풀박스", "박스 포함"처럼 폰과 박스를 함께 파는 글은 `phone`.
- 폰과 다른 기기(워치, 버즈 등)를 함께 팔면 category는 `phone`, models에는 둘 다 적는다.
- 모델명 대신 모델 코드만 있으면 정식명으로 바꾼다 (SM-A155N, A155 → `갤럭시 A15`, A920 → `갤럭시 A9`). 확실하지 않으면 적힌 대로 둔다.
- 가이드 표기 목록에 없는 모델은 같은 표기 스타일로 적는다 (`아이폰 듀오`, `갤럭시 Z 폴드8 울트라`, `갤럭시 폴더2`, `갤럭시 A 퀀텀`). 삼성·애플이 아닌 폰은 제조사명을 붙인다 (`LG X6`).
- 제목의 모델이 존재하지 않는 이름(오타)이고 본문에 바른 모델이 있으면 본문을 따른다 ("S5엣지" + 본문 S25 엣지 → `갤럭시 S25 엣지`).
- 용량 오타가 분명하면 고친다 ("254기가" → `256GB`). 어느 쪽인지 모르면 `[]`.
- 색상: "투명", "클리어"는 색상으로 적지 않는다. 영어 합성 색상은 띄어 쓴다 (`딥 퍼플`, `블랙 티타늄`).
- 판매·구매·교환이 섞인 글은 주된 의도를 따른다. 정말 알 수 없으면 `other`.

## 원칙
- 텍스트에 근거가 있는 것만 적는다.
- 판매 대상이 아닌 언급은 넣지 않는다 (예: "아이폰 15로 바꿔서 14 팝니다" → 14만).
- 교환 희망 기기("17프로랑 교환 원해요")도 넣지 않는다.
